# git-test

## 简介

用于测试 Git 流程的项目仓库。

## 初始化信息

- 仓库地址：https://github.com/Promenade258/git-test.git
- 默认分支：`main`

## 常用命令

```bash
git status                # 查看当前状态
git add .                 # 暂存全部改动
git commit -m "说明"      # 提交
git push                  # 推送到远程 main
git pull                  # 拉取远程更新
```
